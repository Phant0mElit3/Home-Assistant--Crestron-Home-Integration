# Changelog

## 0.1.4

- Adds body-based Quick Action command candidates and detailed Quick Action
  payload diagnostics for live endpoint discovery.

## 0.1.3

- Treats generic Quick Action API-description responses as inconclusive and
  continues trying alternate recall endpoint candidates.

## 0.1.2

- Adds experimental Home Assistant button entities for Crestron Home Quick
  Actions discovered from `/quickactions`.
- Adds live-test logging for likely Quick Action recall endpoint candidates.

## 0.1.1

- Adds Home Assistant/HACS brand images for the Crestron Home integration.
- Updates integration metadata to point at the public GitHub repository.

## 0.1.0

- Initial HACS-ready custom repository package.
- Adds local polling support for Crestron Home lights, thermostats, scenes,
  covers, locks, media rooms, source selection, and sensors.
